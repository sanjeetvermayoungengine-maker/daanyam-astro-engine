# Roadmap

## Sprint 1

- Bootstrap Rust workspace and crate boundaries
- Add canonical contracts with stable serialization
- Implement deterministic timezone and Julian Day utilities
- Add astronomy primitive interfaces and tests
- Define ephemeris backend trait and one test backend adapter
- Deliver minimum Vedic slice
- Deliver minimum API slice
- Add CI, benchmark smoke, and regression placeholders

## Sprint 2

- Replace placeholder astronomy models with validated implementations
- Add Swiss and JPL regression vectors
- Tighten documented error tolerances into enforced assertions
- Expand house calculations and observer models
- Improve API validation and SDK surface

## Deferred beyond Phase 1

- Full yoga library
- Full 16-varga completeness
- Auth, billing, or monetization
- UI applications
